# Mosopefoluwa John — Portfolio

Personal portfolio covering product, engineering, strategy, and biological research.

Live website: https://mosopefoluwa-john.netlify.app/

## Run locally

From this directory, run:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000 in your browser. No dependencies or build step are required.

## Files

- `index.html`: page content and structure
- `style.css`: responsive design
- `site.js`: project details and experience content
- `assets/`: portrait image
- `netlify.toml`: static hosting settings

## Deployment

The site is hosted on Netlify. To connect this repository to the existing Netlify project, select this repository in the project's continuous deployment settings. Use the repository root (`.`) as the publish directory and leave the build command blank.

The latest design simplifies the mobile layout while retaining expandable project details.
